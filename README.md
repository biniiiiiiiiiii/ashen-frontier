# 灰烬边境 · Ashen Frontier

暗黑像素风单人横版动作 RPG。基于 TypeScript、Phaser 3、Vite。无需账号与后端，进度保存在当前浏览器。

## 启动

已安装 Node.js 20.19+ 或 22.12+ 的 Windows 电脑可双击 `启动游戏.cmd`，浏览器将自动打开游戏。

也可以在本目录执行：

```sh
npm install
npm run dev -- --open
```

生产构建：`npm run build`。本地预览：`npm run preview -- --open`。

`dist/` 为已构建的静态网站，可部署到任意静态站点服务器。请通过 HTTP 服务访问，直接双击 dist/index.html 无法正确加载模块。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 上下左右移动 |
| J（可按住） | 三段普通攻击，第三段击退 |
| K | 裂风斩，1 级解锁 |
| L | 旋刃，3 级解锁 |
| U | 破阵突袭，5 级解锁 |
| Space | 闪避，短暂无敌 |
| Enter | 清怪后进入下一个房间 |
| B | 背包，战斗同时暂停 |
| Esc | 暂停或关闭菜单 |
| F | 切换全屏 |

攻击有朝向和纵向范围：与敌人保持接近的纵向位置，并面向敌人。红色地面范围是即将发动的攻击，使用走位或闪避避开。

## 1.1 动作系统更新

- 三段普攻采用快、快、重的独立起手、攻击与收招时序，角色姿态和剑刃轨迹随阶段变化。
- 普攻支持长按，技能需要每次按下触发。输入提前缓冲 0.24 秒；普攻可接技能或闪避，重技能主要攻击阶段不能主动取消。
- 闪避和突袭连续位移；剑气和箭矢按真实飞行路径命中，风行套装产生第二道实体剑气。
- 小怪具有受击硬直、打断和击退；精英重招和 Boss 出招时显示霸体金色轮廓。
- 墓道弓手抬弓锁定方向后射箭，剑气可打断其准备动作；降低弓手占比并拉开射击间隔。
- 骸骨守卫具有近身连斩、蓄力重斩和冲锋，收招时出现破绽提示并承受额外 20% 伤害。
- 原有副本和等级解锁规则继续使用；没有添加独立试炼入口。其他副本接入共用动作底座，本轮招式精修集中在墓道。

## 已实现

- 冒险营地、地下城选择、战斗、结算、商店、背包、设置。
- 三个地下城、六种普通敌人、精英怪与三个 Boss，普通和困难模式。
- 每次冒险三个战斗房间，每房间三波敌人，最后进入首领房间；波次间恢复少量生命，房间间恢复 25% 生命。
- 1–15 级永久成长，技能随等级解锁，失败保留已拾取收益。
- 六部位、四品质、18 个非套装基础模板和 18 个套装模板，随机词条不重复。
- 狂战、风行、余烬三套装备，两件和四件效果可同时生效。
- 困难首领十次内必掉传说；普通首领必掉精良及以上装备。
- 60 格背包、属性对比、穿戴、卸下、锁定、出售、批量出售；满包掉落自动折算金币。
- 自动保存、上一份有效存档备份、损坏恢复、手动导出/导入。
- 页面失焦或切换标签后暂停；音效和震屏开关。
- 程序绘制的像素场景、角色、篝火、粒子、剑光和攻击预警，无外部图片依赖。

## 工程结构

- `src/main.ts`：页面、背包、商店、奖励、成长和交互。
- `src/world.ts`：Phaser 键盘适配、角色姿态、预警、实体弹道和像素场景绘制。
- `src/combat.ts`：动作衔接、输入缓冲、敌人状态、命中、硬直、弹道和房间流程。
- `src/combat-model.ts`：动作时序配置和战斗数据类型。
- `src/data.ts`：数据类型、关卡配置、装备模板、套装和属性计算。
- `src/save.ts`：存档校验、加载、备份和保存。
- `src/style.css`：桌面布局及低高度屏幕适配。

浏览器自动化接口：`window.render_game_to_text()` 返回战斗状态，`window.advanceTime(ms)` 推进模拟时间；这两个接口不会修改装备或直接授予奖励。

## 当前边界

这是可玩的首版，视觉为程序像素素材，Boss 招式与动画仍可继续精修。单局时长、满级所需时间及 60 FPS 目标尚未经过真实玩家长时统计；熟练玩家和成型装备会显著缩短刷图时间。

存档与网站来源绑定：不同浏览器、端口或网址的进度相互独立。建议定期在设置中导出存档。界面使用本地系统字体，游戏启动后不依赖外部字体或图片服务。

详细验证记录见 `验收记录.md`。

验证脚本：在本地预览服务运行时，执行 `node checks/e2e.mjs` 与 `node checks/equipment.mjs`。使用独立的无头 Edge 浏览器会话，不会改动你平时浏览器中的存档。需要本机安装 Microsoft Edge。

新版动作验证：`node checks/actions.mjs`、`node checks/interrupt.mjs`；浏览器测试可调用 `window.setManualTime(true)` 暂停实时推进，再用 `advanceTime(ms)` 按固定步长驱动真实游戏场景，测试结束调用 `setManualTime(false)` 恢复。这个开关不更改角色、装备或敌人状态。

动作更新与验收详情见 `动作系统更新.md`。

## 1.2 墓道与流派更新

- 精准闪避：在攻击判定到来时用 Space 闪避，成功后 1.8 秒内的下一次 J 发动强化反击；不叠加次数，受击会失去机会。
- 蓄力裂风斩：点按 K 快速释放，长按 0.8 秒满蓄、松开释放；蓄力可缓慢移动、可用 Space 取消，剑气实际发出后开始冷却。满蓄伤害为普通剑气的 170%，命中 Boss 完整收招窗口额外增加 25%。
- 墓道九波采用不同配怪与站位；弓手交替使用单射和二连射；裂骨先锋使用横扫接重斩；骸骨守卫半血后可连斩接冲锋，追击段结束后才出现完整破绽。冲锋预警与实际路径共用边界。
- 新增紫色/橙色独立特效装备：曙光回击（反击剑气）、回风坠饰（满蓄剑气折返）、燎原指环（灼烧传播）。六部位与原套装规则保留，装备详情和已穿戴面板展示效果及搭配建议。
- 每份存档首次击败新版墓道首领必得曙光回击；之后普通首领 35%、困难首领 55%概率产出随机特效装备，替代本次首领装备，不额外重复发奖。橙色保底继续生效。商店不产出特效装备。
- 旧存档自动兼容，无需重开；通过 `GAME_URL` 指定验证服务地址，`checks/content.mjs` 检查新操作与特效组合。

## 1.3 墓道轻肉鸽

- 墓道普通、困难每清完一个战斗房间暂停并提供三选一，共三次；Boss房不再追加选择。鼠标或数字1/2/3选择，R刷新整组。
- 12项局内祝福围绕反击、蓄力、灼烧与通用能力展开。首轮尽量提供不同方向，后续抽取对当前装备与已选分支增加权重，同时保留跨流派选择。
- 没有点燃来源时只出现“借火”，点燃后才能抽到火区、灼烧追击；已能点燃时不再抽到重复用途的“借火”。生命充足时不出现即时回血。已选不重复，无升级层数，每局免费刷新一次，刷新后的整组选项与原组不同。
- 剑影继承风行双剑气与回风折返；反击侧向剑气叠加武器的正面剑气；反击各伤害部分共用一次冷却返还。友方余烬火区只伤害敌人，最多6处。
- 祝福、候选与刷新次数只保存在当前战斗内存中。结算、死亡、撤离与刷新页面后清除；等级、金币、装备、解锁与已拾取奖励仍按原规则保存。其他副本保持原刷图流程。
- `checks/roguelite.mjs` 通过真实房间清理、选项与键盘检验能力组合、死亡重试、刷新和存档边界；不直接授予局内祝福。
- `src/blessings.ts` 集中管理祝福数据、触发前提、抽取权重、去重和刷新；战斗控制器执行效果，页面负责暂停选择和展示。

## 自动部署

已提供 GitHub Actions 构建、阿里云 ECS 发布和手动回滚配置。初始化完成后，推送 `main` 自动构建并部署到独立的 8081 端口。服务器专用密钥不进入仓库。首次初始化步骤、发布账户权限及回滚方法见 `deploy/README.md`。
